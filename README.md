# Plugins PGDash para o Claude

## Como instalar

1. No app Claude do computador, abra o Cowork e vá em **Customize › Plugins**.
2. Clique em **Add marketplace** e cole o link deste repositório.
3. Instale o plugin **pgdash-relatorios**.
4. Entre com a sua conta do PGDash quando o Claude pedir e escreva **configurar relatórios**.

Para receber versões novas, clique em **Update** no marketplace e depois escreva **atualizar relatórios**.
